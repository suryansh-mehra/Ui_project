# UI Project

A frontend UI project built using React and Tailwind CSS.
This project demonstrates a modern customer segmentation interface with a clean layout and horizontally scrollable cards.

---

## Features

* Clean and minimal UI design
* Component-based architecture
* Horizontal scrolling card section
* Image overlay cards with text and actions
* Built using Tailwind CSS

---

## Tech Stack

* React (Vite)
* Tailwind CSS

## Installation

Clone the repository

```id="clonecmd"
git clone https://github.com/suryanshmehra/ui-project.git
```

Go to project directory

```id="cdcmd"
cd ui-project
```

Install dependencies

```id="installcmd"
npm install
```

Run the project

```id="runcmd"
npm run dev
```
